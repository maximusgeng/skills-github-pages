# Привет! 👋

Меня зовут **maximusgeng**, и это мой учебный сайт, собранный с помощью
[GitHub Pages](https://pages.github.com/) и генератора статических сайтов
[Jekyll](https://jekyllrb.com/).

## Чему я учусь

Сейчас я прохожу курс **GitHub Skills: GitHub Pages** и параллельно изучаю
дисциплину «Автоматизация разработки программного обеспечения» (АРПО).

В рамках курса я уже разобрался, как:

- включать GitHub Pages из ветки `main`;
- настраивать сайт через `_config.yml` и тему **minima**;
- писать посты в формате Jekyll;
- оформлять текст разметкой Markdown.

и о зеркалировании репозиториев для резервного копирования.
